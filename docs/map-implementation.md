# ACE: расположение логотипов на карте

## Что исправлено

В `assets/css/styles.css` изменены `top`, `left` и `width` восьми логотипов в блоке «Страны — участники». Координаты привязаны к полному изображению карты `assets/images/countries/map.png` размером 2382 × 1722, поэтому при изменении ширины экрана логотипы сохраняют положение относительно береговой линии.

Исходное замечание: [«Комментарии по сайту | АСЕ»](https://docs.google.com/document/d/1iUsqmLMdtUdEDmdtp2dnonSeBH0HlLBJdiXKCODCD8k/edit?tab=t.0), только раздел «Страны участники» с формулировкой «Расположение логотипов бирж отличается от того, как было в дизайне».

Размер и кадрирование самой карты, высота секции, карточки стран и мобильная версия не изменены. Скрипт `assets/js/countries-map.js` также не изменен: он уже строит соединительные линии по фактическим `getBoundingClientRect()` карточек и логотипов. У Ирана остаются две отдельные точки назначения.

## Основание для координат

- Целевой вид: inline object `kix.5oa4slvny3g0`, подпись «Дизайн», изображение 829 × 464.
- Вид до исправления: inline object `kix.a4akt12v53h7`, подпись «Сайт», изображение 1440 × 639.
- Проверенный исходный код: `IMONsergey/ACE-CLIENT-DEPLOY`, commit `a26d24dbf9383e56412f28bff8ae6665eedb00d8`.
- Карта: `assets/images/countries/map.png`, blob `925bac886e3a2309fa95910ab0fafeba62764871`, 2382 × 1722 RGBA.

Расположение восстановлено по клиентскому изображению, а не объявлено точными координатами слоев Figma. В [текущем файле Figma](https://www.figma.com/design/Ya1g999mQznIQYmhI3rU1l?node-id=1-949) узел `1:949` (`world-map-axe-rf (2) 1`) содержит другую карту с семью круглыми флагами. На главной `1:2`, страница `0:1`, восьми соответствующих логотипов нет. В проверенной ранней версии `umGeJGpPYOlwtTRgyE1qw7`, группа `12:320`, также другая карта: страны окрашены, флаги вынесены в легенду. Эти два варианта Figma не использовались как подмена клиентского target.

Оригинальный PNG карты совмещен с береговой линией в целевом изображении без изменения пропорций. Полученное преобразование:

```text
referenceX = nativeX × 0.385638 − 43.538
referenceY = nativeY × 0.385638 − 4.252
```

Полный PNG в координатах изображения «Дизайн» занимает примерно `x = −43.54`, `y = −4.25`, `width = 918.59`, `height = 664.07`. Часть карты обрезана границами исходного изображения 829 × 464. Поэтому проценты нельзя вычислять напрямую от 829 × 464: это внесло бы другое смещение относительно географии.

Положение прямоугольников уточнено по сглаженным краям логотипов. Все восемь исходных PNG в target масштабированы примерно вдвое сильнее, чем карта: масштаб логотипов около 0.1927, карты около 0.3856. Их ширины в CSS восстановлены по пропорции `nativeLogoWidth / (2 × 2382)`. Ограничение точности — примерно один пиксель целевого изображения; три десятичных знака в процентах нужны для стабильного масштабирования, а не означают наличие векторного оригинала target.

## Проверка перед передачей

Проверены исходные изображения, пропорции, совпадение береговой линии и обратное преобразование координат в клиентский target. Проверка отрисовки в браузере выполняется отдельно вместе с общим пакетом изменений.

Критерии приемки на desktop:

1. Видны восемь логотипов семи стран; у Ирана два логотипа.
2. На ширинах 901, 1024, 1440 и 1920 логотипы не пересекаются с карточками стран и друг с другом.
3. В неактивном состоянии нормализованные `getBoundingClientRect()` соответствуют таблице. Для активного логотипа учитывается существующий `transform: scale(1.08)`.
4. Hover и клавиатурный фокус строят линию к новому положению логотипа; для Ирана строятся две линии.
5. После изменения размера окна активные соединения остаются привязаны к логотипам.
6. На ширине 900 и ниже остается отдельная существующая мобильная карта с сеткой флагов.

Остальные замечания документа не входят в это исправление.
