# ACE: верстка для интеграции

В комплекте статические HTML, CSS, JavaScript, изображения и локальные шрифты. Сборка через npm не требуется.

## Страницы

- `index.html`: полная страница сайта, включая карту и новости.
- `news-preview.html`: отдельный блок новостей. Параметр `?article=spief-2025` открывает утвержденную статью сразу.
- `bids-offers/index.html`: существующая демонстрационная верстка Bids & Offers.

Сохраняйте относительные пути и структуру папок.

## Локальный просмотр

Откройте папку комплекта в терминале и запустите любой статический HTTP-сервер. Например:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8080/. Прямое открытие HTML через file:// не рекомендуется: главный экран использует JavaScript-модули.

## Перенос в CMS

Не заменяйте шаблоны CMS целиком статическим index.html. Перенесите нужные секции и подключения в соответствующие шаблоны.

Карта:

1. Перенесите целиком секцию `#countries` из index.html.
2. Сохраните относящиеся к карте правила `assets/css/styles.css` и подключите `assets/js/countries-map.js` один раз.
3. Сохраните `assets/images/countries/`, изображения флагов и локальные шрифты.

Карта и восемь логотипов находятся в одной сцене. Координаты логотипов заданы относительно исходной карты, а не окна браузера. Не добавляйте отдельные сдвиги логотипов на разных разрешениях и не задавайте viewport карты высоту от высоты легенды.

Все описания стран открыты постоянно. При ширине от 1181 px легенда находится слева, при ширине до 1180 px включительно под картой. Соединительные линии включены только в боковой компоновке. У Ирана два логотипа. Если меняется breakpoint, синхронно измените CSS и media query в countries-map.js.

Новость:

1. Подключите `assets/css/news-dialog.css` и `assets/js/news-dialog.js`.
2. Перенесите `dialog#news-dialog`, `template#news-spief-2025` и атрибуты ссылки третьей карточки.
3. Сохраните папку `assets/images/news/article/`.
4. При переносе самого слайдера сохраните его разметку и подключение `assets/js/responsive-slider.js`.

Для других статей добавьте template с ID `news-<slug>` по существующему образцу. На ссылке карточки укажите `data-news-open="<slug>"`, `aria-haspopup="dialog"` и `aria-controls="news-dialog"`. Сохраните настоящий href источника для открытия без JavaScript и через Ctrl/Cmd.

Внутри шаблона сохраняются заголовок `id="news-dialog-title" data-news-title tabindex="-1"`, колонка `data-news-body` и ссылка `data-news-source`. Перед вставкой контента из CMS очищайте HTML штатными серверными средствами.

Программный интерфейс:

```js
window.ACENews.open('spief-2025', triggerElement);
window.ACENews.close();
```

Попап закрывается крестиком, Esc или кликом по фону. После закрытия восстанавливаются фокус и положение страницы. Текст прокручивается внутри окна.

Файлы news-preview.css и news-preview.js относятся только к отдельной демонстрационной странице. В полную страницу сайта их добавлять не нужно.

## Настройки перед запуском

- Замените абсолютные адреса `og:image` и `twitter:image` в основной странице и Bids & Offers на URL целевого домена. Локальное изображение уже есть: `assets/images/meta/social-preview.jpg`.
- Подключите действующие файлы документов и заявлений. Сейчас соответствующие кнопки скачивания выключены, поскольку файлы не включены в этот комплект.
- Основная контактная форма открывает почтовую программу через mailto. Она не отправляет письмо на сервер и не прикрепляет выбранный файл автоматически. Для серверной отправки и загрузки вложений нужен обработчик CMS.
- Вход, регистрация и заявки Bids & Offers представлены демонстрационным интерфейсом без серверной авторизации и базы данных. Данные текущей демо-сессии не следует считать сохраненными на сервере.
- Первые две новостные карточки ведут на официальные страницы SPIMEX. Полные русские материалы для них в комплект не входят.

Сервер должен корректно отдавать HTML в UTF-8, CSS, JavaScript-модули, SVG и WOFF2. Внешние шрифтовые CDN не используются.
